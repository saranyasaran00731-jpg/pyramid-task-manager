# Pyramid – Task Management System

A task management system built for the AbleSpace technical assessment, based on the provided Figma design.

## 🔗 Live Demo
[Click here](https://pyramid-task-manager-one.vercel.app)

## 🛠️ Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Styling: CSS / Responsive UI
- Backend: NestJS, TypeScript
- Database: MongoDB Atlas
- Deploy: Vercel

## ✨ Features
- Guest Login
- Task CRUD
  - Create Task
  - View Task
  - Edit Task
  - Delete Task
- Task status management
  - To Do
  - Doing
  - Completed
  - On Hold
- Complete / Reopen tasks
- List View
- Kanban Board View
- Drag and drop task status change
- Priority management
- Members
- Due dates
- Search
- Status and priority filters
- Clear filters
- Dark / Light theme
- Theme persistence using localStorage
- Responsive design
- Task details modal
- Delete confirmation modal

## 🎨 Design

The application UI was implemented based on the provided Figma design.
