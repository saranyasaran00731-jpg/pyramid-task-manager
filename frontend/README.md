# Pyramid – Task Management System

A full-stack task management app built for AbleSpace technical assessment.

## 🔗 Live Demo
[Click here](YOUR_VERCEL_URL)

## 🛠️ Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: NestJS, TypeScript
- Database: MongoDB Atlas
- Deploy: Vercel

## ✨ Features
- Guest Login
- Task CRUD (Create, Edit, Delete)
- List & Board/Kanban View
- Status: To Do, Doing, Completed, On Hold
- Priority: High, Medium, Low
- Search & Filter
- Theme Switch (Light/Dark + 6 colors)
- localStorage persistence
- Responsive design
- Welcome mascot animation
